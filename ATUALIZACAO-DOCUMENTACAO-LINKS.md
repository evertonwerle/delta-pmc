# Atualização — Documentação com links externos

A aba **Documentação** agora transforma automaticamente URLs HTTP/HTTPS cadastradas no conteúdo em links clicáveis.

- Links para Google Sheets/Planilhas e outras documentações externas podem ser clicados diretamente.
- Os links abrem em nova aba.
- O navegador recebe `noopener noreferrer` para segurança.
- URLs são aceitas sem exigir HTML no conteúdo.
- Quebras de linha continuam preservadas.
- O restante do conteúdo permanece com o padrão visual existente.
